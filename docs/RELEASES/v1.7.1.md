# U4Claude v1.7.1

A small maintenance release — two changes, no migration, no re-login.

## What changed

- **Extra Usage now shows your billing currency's symbol.** The Extra Usage amounts were hardcoded with `$` regardless of your actual currency. They now render the correct symbol for your account — `$`, `€`, `£`, `¥`, `₩`, `CA$`, `A$`, `R$`, or `₹` — falling back to the raw ISO 4217 code for anything unmapped. (No visible change if you bill in USD.) Backport of upstream `4dc411b`, plus KRW (`₩`) for the Korean locale. The format strings in all five localizations moved from a hardcoded `$` to a `%@` placeholder.
- **Spoofed Chrome user-agent bumped 148 → 149**, tracking the current Chrome stable (released 2026-06-02) so Cloudflare's heuristics keep seeing a current browser.

## Internal

- New `ExtraUsageData.currencySymbol` (ISO 4217 → glyph) threaded through `formattedUsageAmount` / `formattedRemainingAmount` / `formattedCompactAmount`.
- +3 `ExtraUsageResponseTests` cases (known codes, case-insensitivity, unknown-code fallback). 53/53 `swift test` pass; Debug build clean, no new warnings.

## Heads-up on update

None. Unlike v1.7.0, this release touches no entitlements or Keychain access groups, so the Sparkle update installs seamlessly — **no re-login required**.
